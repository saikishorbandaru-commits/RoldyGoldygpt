# RoldyGoldy

RoldyGoldy is a mobile-first imitation and bridal jewellery commerce application.

## Core customer journeys
- Browse and discover jewellery
- Product detail and purchase journey
- Wishlist, cart and checkout
- Trial @Home booking
- Jewellery exchange / photo valuation
- Bargaining with jewellers
- Account, orders, invoices and live tracking

> Virtual Try-On has been intentionally discontinued and is not part of the current product scope.

## Local development

### Prerequisites
- Node.js 22+
- Android Studio / Android SDK for Android builds
- Java 21 for the current Android CI setup

### Install
```bash
npm install
```

### Run the web application
```bash
npm run dev
```

### Validate types
```bash
npm run lint
```

### Production build
```bash
npm run build
```

### Sync Android
```bash
npm run android:sync
```

### Build debug APK
```bash
npm run android:apk:debug
```

The debug APK output is generated by Gradle under the Android app build outputs.

## CI release validation

The GitHub Actions workflow validates:
1. Dependency installation
2. TypeScript checking
3. Production web build
4. Capacitor Android sync
5. Android debug APK assembly
6. APK artifact upload on successful builds

See `docs/PHASE_6_RELEASE_READINESS.md` for the final QA and release checklist.
