# Android Release Smoke Test

Use this checklist with the debug APK generated by CI.

## Install
- Download the `roldygoldy-debug-apk` artifact from the successful GitHub Actions run.
- Extract the APK.
- Install it on an Android device.
- Launch the application.

## Critical flow checklist

### Commerce
- [ ] Browse products
- [ ] Open product detail
- [ ] Add/remove wishlist item
- [ ] Add/remove cart item and change quantity
- [ ] Complete checkout path
- [ ] Verify order success

### Trial @Home
- [ ] Check serviceability
- [ ] Select date and slot
- [ ] Complete booking path
- [ ] Verify delivery/return OTP stages where available

### Exchange
- [ ] Open exchange/valuation journey
- [ ] Select image/camera path
- [ ] Complete valuation path

### Bargaining
- [ ] Select product
- [ ] Enter negotiation
- [ ] Accept/apply a deal

### Customer hub
- [ ] Open account
- [ ] Verify profile actions
- [ ] Open orders
- [ ] Open invoice action
- [ ] Open live tracking
- [ ] Open reports/activity

### Authentication
- [ ] Open login/signup
- [ ] Complete available authentication path
- [ ] Verify logout if authenticated

## Acceptance
Record device model, Android version and any defect found. A release candidate should not be marked customer-ready until blocking defects from these critical flows are resolved.
